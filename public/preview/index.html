Le flux 3-CTAs (cliquable dans le téléphone)

1
Hero CTA · "Je découvre la méthode" → scroll vers #methode
Soft CTA. Le visiteur Insta arrive cold, on le warm-up avec la valeur. Pas de paiement avant qu'il ait vu ce qu'il y a dedans.
2
Mid-CTA · "Je rejoins l'académie · 97€" → #checkout
Placé après méthode + apprendre (4 reels). Le visiteur a vu la promesse et ce qu'il va apprendre à faire. Premier point de conversion pour les warm visitors.
3
Ticket / checkout final · "Rejoindre l'académie maintenant"
Après tous les modules + bonus + témoignages + countdown. C'est le ticket récap avec le prix barré 197€ → 97€. Les visiteurs qui scrollent jusqu'ici sont les plus chauds.

Bouton "Commencer" dans le header sticky

Ancre vers #checkout. Visible en permanence pendant le scroll → permet à un visiteur déjà convaincu de checkout à tout moment, sans devoir scroller en bas. C'est ton "déjà décidé ?" intégré.

Tokens design utilisés (alignés brand)

  • .mercury = vrai gradient argent 7 stops de aica-rebrand.css
  • .gold = vrai gradient doré 5 stops des bonus-cards
  • .chrome-cta = vrai gradient + shine sweep + pill 999px
  • .chrome-bubble = labels de section en argent
  • .mercury-green conservé sur le prix 97€ pour conversion (vert = paiement go)
  • Doré (#e9c87b) pour les accents (eyebrow pulse, check garantie, FAQ open, mid-CTA label)

  • Drawer mobile (menu burger) pas inclus pour rester focus — peut être ajouté si besoin
